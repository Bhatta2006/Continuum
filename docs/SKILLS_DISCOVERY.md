# Skills Discovery

Here is the list of skills discovered in the current environment that are relevant to this project:

- **mcp-builder**: Create MCP servers that enable LLMs to interact with external services.
- **ai-agents-architect**: Design AI systems that act autonomously while remaining controllable.
- **ckm:ui-styling**: Create beautiful, accessible user interfaces with shadcn/ui and Tailwind CSS.
- **executing-plans**: Execute approved implementation plans systematically with verification checkpoints.
- **test-driven-development**: Implement features and bugfixes using TDD methodology.
- **verification-before-completion**: Strict verification commands before claiming success.
- **commit**: Use conventional commits and proper formats for PRs.
- **clean-code**: Follow Uncle Bob's Clean Code principles for maintainable and readable code.
- **systematic-debugging**: Debug bugs, failures, and unexpected behaviors systematically.
- **python-pro**: (Optional) Master Python 3.12+ if backend components are built in Python.
- **llm-app-patterns**: Production-ready patterns for building LLM applications.
- **llm-structured-output**: Get reliable JSON and typed objects from LLMs.
- **context-window-management**: Optimize LLM context usage and prevent token limit exhaustion.
